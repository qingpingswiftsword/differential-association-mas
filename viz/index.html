differential-association-mas — Fei Xiaotong's differential mode of association as an organizational prior

费孝通《乡土中国》："社会关系……好像把一块石头丢在水面上所发生的一圈圈推出去的波纹。" 本 demo 把这句话变成可计算的协作协议：每个 agent 维护亲疏表，任务自 ego 投石入水—— 环1 义务必应、收完整上下文；环2 人情可拒、收摘要；覆盖不住，圈子外扩一格。 与无中心扁平自组织（Agensh, 2026 式 claim loop）和中心 orchestrator（星型）同场对比。全部规则化仿真，零 API key，seeded 确定性可复现。

成本结构：token 花在了什么上

同一任务的上下文开销按类型分解：chaxu 花在环内精准投喂（全文只给义务圈、摘要给人情圈）， flat 的成本大头是全员读板（广播即成本），star 的成本是切片全撒 + 提案回收。

规模扫描：成本是否随组织变大而爆炸

差序是 O(k)（环带固定宽度），广播与星型是 O(n)——12 人时三者无差， 96 人时 chaxu 比 flat 便宜 5.3 倍。"涟漪只打湿它需要打湿的人。"

左：按任务批次（每 15 个）的成功率——互惠更新让 chaxu 的涟漪越投越准（或验证它并不改善）。 右：按任务难度分桶（需求技能数 × 难度档）的成功率。

诚实边界：全部 agent 为规则化启发（无 LLM）；token 为统一计费模型（full 200 / digest 40 / slice 60 / proposal 30 / claim-board 100 / claim 10）；star 的 rounds 含中心串行排队（线性增长模型）。 跨多个 seed 的稳定结论：差序格局赢上下文成本（O(k) vs O(n)，规模越大差距越大）、赢故障恢复（外扩即重构）； 成功率不设上限主张。Agensh 论文报告的评测轴（pass rate / latency / 组织特化 / 跨规模涌现协作 / 成本） 在本 demo 中均有对应指标。复现：python run_demo.py --sweep。 License: MIT.
