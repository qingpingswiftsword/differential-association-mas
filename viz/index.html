差序格局 · 多智能体协作最小演示
differential-association-mas — Fei Xiaotong's differential mode of association as an organizational prior

费孝通《乡土中国》："社会关系……好像把一块石头丢在水面上所发生的一圈圈推出去的波纹。" 本 demo 把这句话变成可计算的协作协议：每个 agent 维护亲疏表，任务自 ego 投石入水—— 环1 义务必应、收完整上下文；环2 人情可拒、收摘要；覆盖不住，圈子外扩一格。 与无中心扁平自组织（Agensh, 2026 式 claim loop）和中心 orchestrator（星型）同场对比。全部规则化仿真，零 API key，seeded 确定性可复现。

诚实边界：全部 agent 为规则化启发（无 LLM）；token 为统一计费模型（full 200 / digest 40 / slice 60 / proposal 30 / claim-board 100 / claim 10）；star 的 rounds 含中心串行排队（线性增长模型）。 跨多个 seed 的稳定结论是：差序格局赢上下文成本（环是 O(k)，广播与星型是 O(n)，规模越大差距越大）与故障恢复 （圈子外扩即重构，星型中心死亡归零）；成功率不设上限主张——全员池的 flat/star 在部分 seed 上更高。 复现：python run_demo.py --sweep。 License: MIT.
